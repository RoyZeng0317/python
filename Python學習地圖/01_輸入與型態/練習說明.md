# 第 1 單元：輸入與型態

## 觀念（3 分鐘讀完）

**1. `input()` 拿到的一定是字串**

```python
year = input("年份: ")   # 輸入 2024
print(type(year))        # <class 'str'> → 是 "2024"，不是 2024
```

字串不能拿來做數學計算。`"2024" % 4` 會被當成字串格式化，所以出現你看過的
`TypeError: not all arguments converted during string formatting`。

**2. 要算數學，先轉型**

| 寫法 | 結果 | 什麼時候用 |
|---|---|---|
| `int("2024")` | `2024` | 整數：年份、數量、年齡 |
| `float("1.75")` | `1.75` | 有小數點：身高、體重、匯率、金額 |
| `int("1.75")` | ❌ `ValueError` | 有小數點的字串不能直接轉成 int |
| `str(2024)` | `"2024"` | 數字要接在字串後面時 |

**3. 四捨五入**

```python
round(22.4913, 1)   # 22.5
round(307.6923, 2)  # 307.69
```
